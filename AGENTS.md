# BridgeDev — Agent Instructions

This repository contains the TypeScript-based BridgeDev MCP policy gateway. Preserve and follow the existing security model, operator-authorized approvals, immutable deployed runtime, and audit chain. Read relevant documentation before changing code. Never disable authorization to pass a test. Do not commit secrets or change production services from repository operations. Run `pnpm test` and `pnpm run test:policy` before publishing changes.
